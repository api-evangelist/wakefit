# Wakefit

> Wakefit Innovations Limited (wakefit.co) is an Indian direct-to-consumer home and
> sleep-solutions company founded in 2016 in Bengaluru. It sells memory-foam and
> orthopaedic mattresses, beds, sofas, wardrobes, bedding, decor and the Wakefit Zense
> connected-sleep line through its own e-commerce storefront, an offline retail network
> and Indian marketplaces.

Wakefit publishes **no public API**. There is no developer portal, no API reference, no
machine-readable contract (OpenAPI, AsyncAPI, GraphQL SDL, gRPC/Protobuf or WSDL), no
SDK on any public package registry, no MCP server and no A2A agent card. The host
api.wakefit.co exists but is a private, login-gated internal helpdesk dashboard, not a
developer surface. Everything below is a human-facing page on the company's own site.

## Notes for agents

- www.wakefit.co is served behind a Cloudflare managed bot challenge: non-browser clients
  receive HTTP 403 on every path, including /robots.txt and /.well-known/*.
- The site is a client-rendered single-page app; unknown paths return HTTP 200 with a
  soft-404 body rather than a 404 status.
- Partner and bulk-order access is arranged through web enquiry forms and a sales
  conversation, not through a self-serve API.
